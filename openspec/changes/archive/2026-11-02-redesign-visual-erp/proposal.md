# Proposta: Redesign visual do sistema

## Problema
A interface atual apresenta inconsistências visuais entre as telas, excesso de espaços vazios, navegação pouco clara e gráficos com baixa legibilidade. A tela inicial e o login também não apresentam um fluxo visual adequado.

## Objetivo
Padronizar a experiência visual do sistema com uma interface moderna, clara e profissional, mantendo as funcionalidades existentes.

## Escopo
- Reformular a tela inicial e o fluxo de acesso/login.
- Padronizar cores, tipografia, espaçamentos, botões, formulários e navegação.
- Aplicar o padrão visual às telas existentes do sistema.
- Melhorar a apresentação de gráficos e tabelas.
- Tratar mensagens de erro de autenticação com textos claros para o usuário.

## Fora do escopo
- Alterar regras de negócio, cálculos ou permissões.
- Alterar endpoints, payloads ou estrutura do banco de dados.
- Adicionar funcionalidades novas.

## Critérios de sucesso
- As telas seguem uma identidade visual consistente.
- A tela inicial e o login aparecem em etapas separadas, sem sobreposição.
- A interface evita espaços vazios excessivos e rolagem desnecessária em resoluções comuns de desktop.
- Gráficos e tabelas permanecem legíveis em fundos claros.
- Erros de login são apresentados em linguagem amigável, sem expor respostas técnicas do backend.
